# Map data source and license

No offline map dataset is currently present in the app or tablet. The intended
initial region is Ahmedabad. BBBike advertises custom Mapsforge extracts; its
download service requires request submission and supports Mapsforge output.
The map attempt in this phase was blocked by local certificate validation and
did not bypass TLS. No public OSM raster tile bulk download was performed.

OpenStreetMap data is © OpenStreetMap contributors and distributed under the
ODbL. Display attribution in-app. BBBike extraction is provided for general
end-user use under its fair-use terms; commercial/redistribution needs must be
reviewed with BBBike. Mapsforge library is LGPLv3. Source: [BBBike output formats](https://extract.bbbike.org/extract-dialog/en/format.html),
[BBBike help/terms](https://extract.bbbike.org/extract.html),
[Mapsforge license](https://github.com/mapsforge/mapsforge).
